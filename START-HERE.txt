TO PUT THE SITE ONLINE
----------------------
Upload EVERYTHING inside the  deploy/  folder to your web host.

Upload the CONTENTS of deploy/, not the folder itself, so that
deploy/index.html becomes https://www.letterboxlock.sg/index.html

  This folder  ->  relative paths  ->  opens by double-click
  deploy/      ->  absolute paths  ->  correct on a web server

TO EDIT ANYTHING
----------------
  src/data/site.json   products, prices, reviews, FAQs, service areas
  src/data/i18n.mjs    every button and label, English and Chinese

Change a price in site.json and it updates in all five places at once.

  npm run package     rebuild BOTH (this folder + deploy/)
  npm run all         build + 61 tests + full validation
  npm run dev         build and serve at http://localhost:8080
  npm run images      regenerate the 31 sample images

No npm install needed. Zero dependencies.
